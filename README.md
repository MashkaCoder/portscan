# Port scan

Go-пакет для проверки доступности TCP-портов на одном или нескольких хостах c поддержкой конкретности, контекста и гибкой настройкой параметров работы. 

 ## Установка 
```
go get github.com/MashkaCoder/portscan
```

## Описание
### Создание сканера
```go

scan := portscan.New()
```
Настройки
|Опция|Описание|По умолчанию
-------|--------|--------------
WithConcurrency(n int)|Количество одновременно выполняемых проверок|10
WithTimeout(t time.Duration)|Таймаут подключения к порту|500ms
WithResolvedAllIPs(all bool)|Проверять все IP для DNS-имени|false
WithBufferSize(size int64)|Размер буфера для каналов|100

### Работа с портами

```go
// Список отдельных портов
ports := portscan.List(80, 443, 8080)

// Диапазон портов
ports := portscan.Range(1, 1024)

// Комбинация списков и диапазонов
ports := portscan.Combine(
    portscan.List(80, 443),
    portscan.Range(3000, 4000),
    portscan.List(8080, 8443),
)

```
Методы возвращают `portscan.Ports`, необходимый для дальнейшего сканирования

### Сканирование
```go
results, err := scanner.Scan(ctx, hosts, ports)
```
Параметры:

- `ctx` - контекст для отмены операции (`context.Context`)

- `hosts` - список хостов (IPv4, IPv6, DNS-имена) (`[]string`)

- `ports` - набор портов для проверки (`portscan.Ports`)


Возвращает:

Канал результатов `<-chan Result`, `error`

Ошибки:

- `no hosts given` - пусто список остов

- `no ports given` - пустой список портов

## Структура результа проверки доступности порта
```go
type Result struct {
    Host     string        // исходный хост
    IP       net.IP        // IP, к которому подключались
    Port     uint16        // номер порта
    State    State         // состояние порта
    Duration time.Duration // время проверки
    Err      error         // ошибка
}
```
### Состояние порта
Состояние|	Описание	|
---------|------------
Open	|TCP-соединение установлено	|
Closed	|Соединение явно отклонено|
Timeout	|Превышен таймаут	|
Unreachable	|Хост или сеть недоступны	|
Canceled	|Отменено через context	|
Error	|Произошла другая ошибка	|

## Поведение
### Хосты
- Пустые хосты внутри списка- игнорируются
  
- Пустой список хостов - возвращает ошибку

- Некорректный адрес -  возвращает Unreachable

- Неразрешимое DNS-имя - возвращает Unreachable

- Повторяющиеся хосты - проверяются один раз

- DNS с несколькими IP - по умолчанию проверяется только первый IP (можно включить все через WithResolvedAllIPs)

### Порты
- Порт 0 - игнорируется

- Порт > 65535 - игнорируется (невозможен из-за типа uint16)

- Обратный диапазон (1000-1) - автоматически преобразуется в 1-1000

- Повторяющиеся порты - проверяются один раз

- Пустой список портов - возвращает ошибку

### Конкурентность
- Проверки выполняются параллельно в воркерах

- Количество воркеров настраивается через WithConcurrency

- Буферизированные каналы для предотвращения блокировок

- Корректная обработка отмены через context.Context

- Закрытие каналов после завершения работы
